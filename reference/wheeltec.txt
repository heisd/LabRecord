解决方法:
在工作空间里面find一下
find . src/control_msgs
如果出现这个
find: ‘src/control_msgs’: 没有那个文件或目录
那么就在使用这个指令
使用apt安装的
sudo apt install ros-humble-control-msgs
sudo apt install libnlopt-dev
前面的ros-humble是ros版本,后面的是缺少的包
运行source ./install/setup.bash 设置编译环境
如果使用这个指令找不到吧可以有两种选择一个是从源码进行编译,一个是安装对应的库
比如说这个nlopt我们就找不到apt
这里为了方便我们从安装对应的库
sudo apt install libnlopt-dev

这个代表你装的boost和系统的冲突啦
解决boost冲突问题
删除以前的boost
sudo rm -rf /usr/local/lib/cmake/Boost-1.75.0
sudo rm -rf /usr/local/include/boost
sudo rm -f /usr/local/lib/libboost_*
安装新的boost文件
sudo apt install --reinstall libboost-all-dev
source ./install/setup.bash
colcon build --packages-skip-build-finished --continue-on-error
